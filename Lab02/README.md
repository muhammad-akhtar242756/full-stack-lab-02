# Full Stack Web Development - Lab 02

## Topic
Advanced CSS and Bootstrap Flex Utilities

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- Visual Studio Code
- Git and GitHub

## Concepts Covered
- Advanced CSS properties
- CSS Flexbox
- CSS positioning
- CSS display concepts
- CSS pseudo-elements
- CSS filters
- CSS transitions
- CSS transforms
- Bootstrap Flex utility classes
- Responsive web design

## Project Description
This project is a simple student portfolio webpage. It contains a navigation bar,
hero section, profile section, skills, projects, Bootstrap Flexbox demonstration,
CSS positioning example, contact section and footer.

Custom CSS is used to improve the layout and add effects such as hover movement,
image zooming, grayscale filtering, shadows, gradients and pseudo-elements.

## How to Run
1. Open the project folder in Visual Studio Code.
2. Open `index.html` in a browser.
3. For a better experience, use the Live Server extension.
4. Resize the browser to test desktop, tablet and mobile layouts.
